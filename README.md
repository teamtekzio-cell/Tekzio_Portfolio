## 🌾 Featured — Crop Disease Detection System

A deep learning system that diagnoses plant disease from a single leaf photo. Built with CNN transfer learning and fine-tuned on the **Bangladesh Multi-Crop Disease Classification Dataset (2025)** — 123,588 real-world images across 94 disease classes and 13 crop varieties.

- Transfer learning on pre-trained CNN backbones (VGG16 / ResNet / EfficientNet family)
- Real-world field imagery — not just lab conditions — for strong generalisation
- Lightweight architecture targeting low-cost smartphones used by smallholder farmers
- **Grad-CAM** explainability highlighting the exact diseased region on the leaf
- Instant diagnosis from a single uploaded photo — no expert inspection needed

Crop diseases destroy an estimated **20–40% of global yields** each year. This puts accurate, explainable diagnosis in any farmer's pocket.

## 🛠️ How to Run Locally

No build tools or dependencies needed — it's a single HTML file.

```bash
# Clone the repository
git clone https://github.com/your-username/tekzio-portfolio.git

# Navigate into the folder
cd tekzio-portfolio

# Open in your browser
open index.html
# or just double-click index.html
```

## 🌍 Deploy with GitHub Pages

1. Go to your repository on GitHub
2. Click **Settings** → **Pages**
3. Under **Source**, select `main` branch and `/ (root)`
4. Click **Save**
5. Your site will be live at `https://your-username.github.io/tekzio-portfolio`
